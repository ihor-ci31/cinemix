## Сторінки сайту (ЛР1)
| Файл | Опис |
|------|------|
| `index.html` | Головна сторінка |
| `catalog.html` | Каталог фільмів (6+ карток) |
| `movie.html` | Детальна сторінка фільму |
| `about.html` | Про сервіс + контакти |
| `register.html` | Форма реєстрації з HTML5-валідацією |

## Технічний стек (ЛР1)
- HTML5 (семантична розмітка)
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Inter, Montserrat)
- Чиста JavaScript (бургер-меню, валідація форм)

## Запуск
Відкрити `index.html` у браузері — сервер не потрібен.
